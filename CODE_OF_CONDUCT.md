# Code of Conduct (行为准则)

This project community follows a simple, neutral code of conduct:

- Be respectful and constructive in all interactions.
- No harassment, discrimination, or personal attacks — in any language.
- Focus feedback on the work, not the person.
- Respect account boundaries: theory / product / evaluation lines are intentionally isolated.

Violations may be reported via the repository's SECURITY contact channel and will be reviewed by the account owner.

*This document is provided AS IS and is not a legal commitment beyond the above principles.*
